# 2026-08-05 full-corpus rerun

All 17 volumes with truth data, re-run end to end: `split` -> `keymap-detect` -> `craft --resume` ->
`adjacency` -> `keymap` -> `ocr` -> `fit`. CRAFT boxes were reused where cached; everything else
was regenerated. OCR ran **without** `--resume` so the rebuilt key maps actually reached each
page's vocabulary (`mapsnap rerun` passes `--resume`, which would have skipped every page).

Run in two lanes -- one OCR at a time, one fit at a time, overlapping -- from 20:54 to 01:44 (4h50m).
